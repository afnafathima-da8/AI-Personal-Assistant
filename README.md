# 🤖 AI Personal Assistant – n8n Automation

## 📌 Project Overview

An AI-powered personal assistant developed using n8n that automates everyday tasks through natural language interactions.

The assistant uses OpenAI to understand user messages and connects with Google services to perform automated actions.

## 🛠️ Technologies Used

- n8n – Workflow Automation
- OpenAI – AI Agent and Natural Language Processing
- Google Calendar – Event Creation
- Gmail – Email Automation
- Google Sheets – Spreadsheet Data Retrieval

## ⚙️ Features

- AI-powered conversational assistant.
- Automated Google Calendar event creation.
- Gmail integration for sending emails.
- Google Sheets integration for retrieving information.
- Natural language-based task automation.

## 🔄 Workflow

1. User sends a message to the AI assistant.
2. OpenAI processes the user's request.
3. AI Agent determines the required action.
4. Google Calendar creates events when requested.
5. Google Sheets retrieves spreadsheet information when needed.
6. Gmail sends emails when requested.

## 🚀 Setup Instructions

1. Download the JSON workflow.
2. Import it into n8n.
3. Configure your OpenAI credentials.
4. Connect your Google Calendar, Gmail and Google Sheets accounts.
5. Test the workflow.

## 🎯 Project Objective

To simplify everyday tasks by building an AI assistant that connects multiple Google services through workflow automation.
